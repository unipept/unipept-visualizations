Treeview of the flare hierarchy

The same treeview on D3's flare sample data, the package hierarchy of an old ActionScript visualization toolkit. levelsToExpand: 1 opens a single level per click rather than the default two, which suits a deep and narrow tree, and enableTooltips: false drops the hover labels because this dataset has no counts to report.
